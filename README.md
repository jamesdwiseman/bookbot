# bookbot

BookBot is my first [Boot.dev](https://www.boot.dev) project!


curl downloads the content from the URL
-o mobydick.txt says "save it to a file called mobydick.txt"
If you didn't use -o, you'd see thousands of lines of text from Moby Dick scrolling by on your terminal screen, but it wouldn't be saved anywhere!

The -o is followed by the filename you want to create. So -o mobydick.txt creates a file called mobydick.txt with the downloaded content.
